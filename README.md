# 🎯 Detector de Disparos - Interfaz Canvas Visual

## 📋 Descripción

Interfaz visual interactiva en **HTML5 Canvas** para visualizar el sistema de **Detección de Disparos con Gemini 2.0 Flash AI**.

## 🎨 Características

✨ **Visualización en Tiempo Real**
- Mapa de detección GPS interactivo
- Espectrograma de frecuencias dinámico
- Ondas de propagación animadas
- Partículas visuales
- Grid de coordenadas

📊 **Indicadores Técnicos**
- Gauge de confianza (0-100%)
- Medidor de decibeles
- Display de frecuencia pico
- Análisis de datos en vivo

🏛️ **Panel de Autoridades**
- 7 Autoridades integradas
- Estado de envío de reportes
- Código de colores

📝 **Log de Eventos**
- Registro en tiempo real
- Colores según tipo de evento
- Scroll automático

## 🚀 Cómo Usar

### 1. Clonar el Repositorio
```bash
git clone https://github.com/rogelioglz/Detector-Disparos-UI.git
cd Detector-Disparos-UI
```

### 2. Abrir en el Navegador
```bash
open index.html
# O simplemente arrastra index.html a tu navegador
```

### 3. Interactuar
- **▶ Simular Detección**: Inicia la simulación de detección de disparo
- **📄 Generar Reporte**: Genera reporte con Gemini AI
- **🗑️ Limpiar**: Resetea la interfaz

## 🎮 Simulación

Haz clic en "Simular Detección" para:
1. Activar animación de ondas
2. Pulsación de partículas
3. Envío automático a autoridades
4. Generación de reporte AI
